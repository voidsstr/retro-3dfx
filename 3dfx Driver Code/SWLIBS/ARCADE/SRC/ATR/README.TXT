The ATR directory contains source files for the Arcade Toolbox
Rendering library.

atrender.h - public header file for atrender library
fxatr.h    - private header file for atrender library

rstate.c  - libary global data and state management
rrender.c - Rendering Routines
xatr.asm  - libary assembly functions
rstats.c  - Statistic Compilation Functions

rvertex.c - Vertex Class
rxform.c  - XForm Class
rtex.c    - Texture Class
rcanvas.c - Canvas Class
renv.c    - Env Class
rcamera.c - Camera Class
rtri.c    - TriSet Class
rlight.c  - Light Class
rmat.c    - Material Class
