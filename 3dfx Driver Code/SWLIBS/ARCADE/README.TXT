The Arcade Toolbox:

To Build:

First build GLIDE.LIB, FXMISC.LIB, GCI.LIB
Set BUILD_ROOT_ARCADE to point at this directory.
Call "nmake all" in this directory

To Run Apps:
Set AT_LOAD_PATH to point to any directories containing model or 
texture files

SUBDIRS:

CMD     - Arcade Toolbox sample application sources
SRC     - Library sources
DRIVERS - Driver sources
INCLUDE - Public headers
LIB     - Public libraries
DATA    - Sample data files
