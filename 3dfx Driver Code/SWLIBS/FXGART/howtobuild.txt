Make sure you have installed the DX5 DDK, the Windows 95 DDK, and the Windows 
SDK.  Then set the following environment variables (after you have the MSVC 
environment setup--as with VCVARS32).


DXDDK=<top of DX5 DDK installation)
W95DDK=<top of Windows 95 DDK installation)
MSDDK=<top of Windows SDK installation)
SIW95=(top of SoftIce W95 installation)

Then run nmake.
