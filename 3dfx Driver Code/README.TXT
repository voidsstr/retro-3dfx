What's in the distribution?
=======================================================================
This Diagnostic kit distribution contains diagnostics tools, and
test utilities for Glide2x & Glide3x.

=======================================================================
Installation 
=======================================================================

Requirements
------------

- 3Dfx Voodoo Based Graphics Accelerator
- Windows 95 Glide2x or Glide3x Driver
- Windows NT 4.0 Glide2x or Glide3x Driver
Optional:
-Glide2x or Glide3x SDK

Installation
------------
Unzip this Diagnostics kit with path information to the root of your
3Dfx build tree.  

Glide SDKs have the following tree structure:
	3Dfx\SDK\[Glide API]\...

For example, if you unzip to c:\, the SDK will create
	c:\3Dfx\SDK\Glide3x\
and assorted subdirectories under Glide3x.

Note that you may install this adjacent to the Glide2x SDK:
	3Dfx\SDK\Glide3x\
	3Dfx\SDK\Glide2x\


Notice
------
The Pass.exe utility found under the utils\OS directory should only
be used on Voodoo Graphics and Voodoo2 Video Accelerators.  Adverse
effects will occur on Voodoo Rush and Voodoo Banshee Video Accelerators.

Video Driver Installation
-------------------------  
This kit does not include video drivers.
Video drivers for Voodoo Graphics, Voodoo Rush, and Voodoo2 should be
provided by the card manufacturer.  Reference drivers can be download
from the 3Dfx Interactive, Inc web site listed above.

Follow installation instructions provided with driver kits.
