   History of Releases for Voodoo4 Manufacturing Diagnostics
===============================================================
Release N_7a   4/26/00:
- Changed memory mapping size to 32Mb.

Release N_7    4/24/00:
- Corrected pciCfgDecode settings for memory test of slave device.

Release N_6    3/27/00:
- Cleaned up memory test for slave device.

Release N_5d    3/24/00:
- Changed the slave PCI base address 0 setting to 384Mb to see if
  this would fix problems with some AGP boards not properly reading
  the IO registers on the slave device.

Release N_5c    3/24/00:
- Changed the slave PCI base address 0 setting to 128Mb to see if
  this would fix problems with some AGP boards not properly reading
  the IO registers on the slave device.

Release N_5b    3/24/00:
- Changed the slave PCI base address 0 setting to 256Mb to see if
  this would fix problems with some AGP boards not properly reading
  the IO registers on the slave device.

Release N_5a    3/24/00:
- Store the dramInit and power-on strapping pin register values in log file.

Release N_5    3/23/00:
- The slave memory test now works on AGP boards.

Release N_4    3/22/00:
- Corrected problem with slave memory failures not returning an error
  message.
- Dual texture test is fixed.
- Removed 3d splash test due to problem with it locking up the system
  using the latest Glide library.
- The correct name of board is now displayed based on the PCI subsystem ID.


Release N_3    3/14/00:
- Works with both single and 2-way SLI boards. Corrected problem with
  /sli switch always being set even if it was not added on the command
  line. This caused previous version to hang on single chip boards.


Release N_2    3/10/00:
- Added /sli switch.  This switch will enable memory testing of
  the slave device on SLI boards.
  Example:  mdc /basic /sli  <== this will test the memory of both
 				 the master and slave on the sli board.


Release N_1    2/2/00:
- Initial release of Voodoo4 diagnostic.
- Changed PCI Device ID to 9.
